How to install (Android)

  1. Tap Download above. If Chrome asks, tap Download anyway.
  2. When it finishes, tap Open (or find the file in your Downloads).
  3. If your phone says the source is not allowed, tap Settings and turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect shows a message, tap More details then Install anyway.
  5. Open the app and sign in.
